# Math Learning Game for Autism Kids

A comprehensive ReactJS application designed to help children with autism learn mathematics through interactive games and visual activities.

## Features

- 🔢 **Number Recognition** - Learn to count and identify numbers with visual objects
- ➕ **Addition Game** - Practice addition with colorful emoji representations
- 🎨 **Pattern Matching** - Improve memory through pattern completion exercises
- 📊 **Progress Dashboard** - Track learning progress with interactive charts
- 🏆 **Achievement System** - Unlock badges for milestones

## Autism-Friendly Design

- Calm, non-overwhelming color schemes
- Large, clear fonts and buttons
- Immediate visual feedback
- Self-paced learning
- No time pressure or competition
- Consistent UI across all pages

## Tech Stack

- **React 18+** - Modern React with Hooks
- **React Router 6** - Multi-page navigation
- **Recharts** - Data visualization
- **CSS3** - Responsive, animated styling
- **LocalStorage** - Progress persistence

## React Concepts Demonstrated

- Functional Components
- Class Components (ProgressTracker)
- React Hooks (useState, useEffect, useContext)
- Context API for global state
- React Router for navigation
- Props and PropTypes
- Event Handling
- Conditional Rendering
- Forms and Controlled Components
- Component Lifecycle

## Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
